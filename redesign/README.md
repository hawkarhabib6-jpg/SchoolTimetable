# بەشی چوارەم — تاقیکردنەوەی داتاشراوی یەکەم (ڕیدیزاین)

دووبارە داڕشتنەوەی پرۆفیشناڵی پەڕەکانی وانەی **٤–١ تاقیکردنەوەی داتاشراوی یەکەم**
(بیرکاری، پۆلی ١٢ی زانستی). سەرچاوەکە PDFـێکی سکانکراوی ٢٩ پەڕەیی بوو؛ ئەم وەشانە
تەواوی ناوەڕۆکەکەی دووبارە ڕیزبەند کراوەتەوە وەک دۆکیومێنتێکی HTML کە دەبێتە PDF.

**بەرهەمەکان** (هەردووکیان ٣٦ پەڕەی A4):

- [`بەشی-چوارەم-تاقیکردنەوەی-داتاشراوی-یەکەم.pdf`](./بەشی-چوارەم-تاقیکردنەوەی-داتاشراوی-یەکەم.pdf) — بۆ چاپکردن
- [`بەشی-چوارەم-تاقیکردنەوەی-داتاشراوی-یەکەم.docx`](./بەشی-چوارەم-تاقیکردنەوەی-داتاشراوی-یەکەم.docx) — بۆ دەستکاریکردن لە Word

## چی گۆڕا

| پێشتر | ئێستا |
|---|---|
| دەقی وێنەکراو (screenshot) بۆ هاوکێشەکان | ڕیزبەندی ڕاستەقینەی بیرکاری بە KaTeX — تیژ لە هەر گەورەکردنێکدا |
| خشتەی هێما وەک وێنە | خشتەی HTML، بە تیر و هێمای ڕەنگکراو و چوارچێوەی یەکگرتوو |
| ٧–٨ ڕەنگی جیاواز لە یەک لاپەڕەدا | سیستەمێکی ڕەنگی سنووردار: شین (بنەڕەت)، سەوز (زیادبوون)، سوور (کەمبوون)، ئەمبەر (ساڵی تاقیکردنەوە) |
| فۆنتی ناڕێک و قەبارەی جیاواز | Noto Kufi Arabic بۆ سەردێڕ + Noto Sans Arabic بۆ دەق، پێوانەیەکی یەکگرتوو |
| ناونیشانی تێکەڵ | پێکهاتەی دیاریکراو: کارتی چەمک، نموونە، پرسیاری وەزاری، تێبینی، ڕاهێنان |
| بێ پێڕست | بەرگ + پێڕستی ناوەڕۆک + سەردێڕ/پێڕەوی ژمارەی لاپەڕە لە هەموو پەڕەیەک |

وێنەی نەخشەکان (گرافەکان) لە سەرچاوەکەوە هێنراون و پاککراونەتەوە (وشکاندنی
واتەرمارک و چوارچێوە)، چونکە داتای ڕەسەنیان لەودان.

## پێکهاتەی فایلەکان

```
redesign/
├─ index.html      ناوەڕۆکی تەواو (بەرگ + ٣٥ پەڕەی ناوەڕۆک)
├─ styles.css      سیستەمی دیزاین: توکن، پێکهاتەکان، ڕیزبەندی چاپ A4
├─ paginate.js     دابەشکردنی ناوەڕۆک بەسەر پەڕەکاندا + سەردێڕ/پێڕەو
├─ mk.py           یاریدەدەری نووسین (خشتەی هێما، پرسیار، نموونە، ...)
├─ render.mjs      HTML → PDF بە Playwright
├─ to-docx.mjs     HTML → Word (.docx) — هاوکێشەکان دەکرێن بە هاوکێشەی ڕەسەنی Word
├─ toc.mjs         ژماردنی لاپەڕەی بەشەکان بۆ نوێکردنەوەی پێڕست
├─ figs/           ٤٣ وێنەی نەخشە (٣٤٠ dpi، بێ واتەرمارک)
├─ fonts/          Noto Kufi Arabic + Noto Sans Arabic
└─ vendor/katex/   KaTeX ٠.١٦ (woff2)
```

## دروستکردنەوەی بەرهەمەکان

```bash
npm install playwright docx   # جارێک (پێویستە pandoc دابمەزرێنرێت بۆ .docx)
node render.mjs               # → PDF
node to-docx.mjs              # → Word (.docx)
```

`index.html` لە وێبگەڕیشدا ڕاستەوخۆ دەکرێتەوە — هەمان دەرئەنجام بێ چاپکردن.

### دەربارەی فایلی Word

- هاوکێشەکان **هاوکێشەی ڕەسەنی Word**ن (OMML) — دەکرێت دەستکارییان بکەیت،
  نەک وێنە. بە `pandoc` لە LaTeXـەوە دەگۆڕدرێن.
- خشتەی هێما و خشتەکانی تر خشتەی ڕاستەقینەی Wordن.
- فۆنتی دۆکیومێنتەکە **Tahoma**ـە، چونکە لە هەموو وەشانێکی Word هەیە و
  پیتەکانی کوردی بە تەواوی پشتگیری دەکات.
- ماوەکان (وەک `]−∞,0[`) وەک دەقی ساکار نووسراون نەک هاوکێشە، بۆ ئەوەی
  لە LibreOffice/Google Docsـیشدا ڕاست دەربکەون.

## تێبینی دەستکارییەکان

ناوەڕۆکەکە بە دڵسۆزی وەرگیراوە. لە دوو شوێندا هەڵەی چاپی سەرچاوەکە ڕاستکراوەتەوە
بەپێی خشتەی هێمای خۆیان:

- ماوەی ڕوو لە زیادبوونی \(f(x)=x-4\sqrt{x+1}\) — `]3,+∞[` لەبری `]−1,+∞[`
- نرخی \(f\) لە خاڵی `x=5π/3` بۆ \(f(x)=\tfrac{x}{2}-\sin x\) — `5π/6` لەبری `5π/3`
