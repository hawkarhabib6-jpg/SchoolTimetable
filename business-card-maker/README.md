# Business Card Maker — دروستکەری بزنس کارت

بەرنامەیەکی مۆبایل (Android / iOS) بە **React Native + Expo + TypeScript** بۆ دیزاینکردنی بزنس کارتی پیشەیی و ئامادەی چاپ (٣٠٠ DPI).

---

## تایبەتمەندییەکان

### ١. فرە‌زمانی و RTL
- کوردی (سۆرانی)، عەرەبی، ئینگلیزی
- ئاراستەی ڕووکار خۆکارانە دەگۆڕێت (RTL بۆ کوردی/عەرەبی، LTR بۆ ئینگلیزی) — **بەبێ پێویستبوون بە ڕیستارتکردنی ئەپەکە**
- لە یەکەم جار زمانی ئامێرەکە دەناسێتەوە (`expo-localization`)
- فۆنتە ڕەسەنەکان: Cairo، Tajawal، Noto Sans Arabic، Vazirmatn (عەرەبی/کوردی) و Montserrat، Poppins، Inter، Roboto، Playfair Display (لاتینی)

### ٢. مەکینەی دیزاین
- پێشبینینی ڕاستەوخۆ بۆ **هەردوو ڕووی کارتەکە** (پێشەوە/دواوە)
- ڕاکێشان بە دەست (drag) + گۆڕینی قەبارە بە چوار گۆشەکەوە + لکاندن بە تۆڕەوە (snap to grid)
- کۆنترۆڵی ورد بۆ شوێن: سلایدەری X و Y بۆ هەر توخمێک (بۆ کاتێک ڕاکێشان بە دەست تەواو ورد نییە)
- کۆنترۆڵی تەواوی نووسین: فۆنت، قەبارە، قەڵەوی، دووری دێڕ و پیت، ڕیزبەندی، پیتی گەورە، ڕەنگ
- وێنە و لۆگۆ: هەڵگرتن لە گەلەری یان کامێرا، بڕین بۆ بازنە یان چوارگۆشە، سووڕاندن ٩٠°، چوارچێوە، سێبەر، ڕوونی
- شێوەکان: لاکێشە، بازنە، هێڵ، سێگۆشە + ڕەنگی تێکەڵ (gradient) + پرێسێتی داپۆشەری ڕەنگ و هێڵی جیاکەرەوە
- ئایکۆنەکانی Lucide (٥٠ ئایکۆنی هەڵبژێردراو)
- پاشبنەما: ڕەنگی تەواو، gradient (١٠ پرێسێت)، نەخش (خاڵ، تۆڕ، لار، شەپۆل)
- QR: بە شێوەی خۆکار لە زانیاری پەیوەندییەکەت (vCard) دروست دەبێت، یان هەر دەق/لینکێکی تایبەت
- چینەکان (layers)، پاشگەزبوونەوە/دووبارەکردنەوە (undo/redo)، قوفڵکردن، لەبەرگرتنەوە

### ٣. تێمپلەیتە ئامادەکان
١٥ دیزاینی پیشەیی لە ٥ جۆردا — مۆدێرن/تەکنەلۆژیا، کارگێڕی، سادە، داهێنەرانە، کلاسیک.
هەموویان هەردوو ڕوویان هەیە و دوای هەڵبژاردن **هەموو توخمەکانی دەستکاری دەکرێن**.

### ٤. هەناردەکردن
- PNG و JPEG بە **١٠٥٠ × ٦٠٠ پیکسڵ = ٣.٥ × ٢ ئینچ لە ٣٠٠ DPI**
- PDF بە قەبارەی وردی کارت (بژاردەی بلیدی ٣ ملم بۆ چاپخانە)
- فایلی `.vcf` (vCard) بۆ ناردنی زانیاری پەیوەندی
- هاوبەشکردن ڕاستەوخۆ لە ڕێگەی `expo-sharing`

### ٥. هەڵگرتنی داتا
هەموو دیزاینەکان لەناو ئامێرەکەدا هەڵدەگیرێن (`AsyncStorage`) — پاشەکەوت، گۆڕینی ناو، لەبەرگرتنەوە، سڕینەوە.

---

## پێکهاتەی فۆڵدەرەکان

```
business-card-maker/
├── App.tsx                    # ڕەگی ئەپەکە + providerەکان
├── app.json / eas.json        # ڕێکخستنی Expo و EAS Build
└── src/
    ├── components/            # کانڤاس، ڕێندەری توخمەکان، هەڵبژێرەکان
    │   ├── panels/            # پانێلەکانی خاسیەت (نووسین، وێنە، پاشبنەما، ...)
    │   └── ui/                # دوگمە، سلایدەر، شیت، ...
    ├── context/               # SettingsContext, CardsContext, EditorContext
    ├── i18n/                  # ckb.ts, ar.ts, en.ts + ناوکی وەرگێڕان
    ├── navigation/            # تابەکان + ستاک
    ├── screens/               # کارتەکانم، تێمپلەیت، دیزاین، هەناردە، ڕێکخستن
    ├── storage/               # AsyncStorage
    ├── templates/             # ١٥ تێمپلەیتی ئامادە
    ├── theme/                 # ڕەنگ، فۆنت، سپەیسینگ
    ├── types/                 # مۆدێلی داتای کارت
    └── utils/                 # هەناردە، vCard، وێنە، ژمێریاری
```

### بیرۆکەی سەرەکی: «یەکەی کارت»
هەموو شوێن و قەبارەیەک بە یەکەی کارت هەڵدەگیرێت (١٠٥٠ × ٦٠٠). ڕێندەرکردن لە هەر قەبارەیەکدا تەنها یەک `scale`ە، و هەناردەی ٣٠٠ DPI واتە `scale = 1`. بۆیە ئەوەی لەسەر شاشە دەیبینیت ١٠٠٪ وەک ئەوەیە کە چاپ دەبێت.

## دامەزراندن

```bash
cd business-card-maker
npm install

# وەشانەکان بەپێی SDK ی Expo ڕێک بخە (پێشنیارکراوە)
npx expo install --fix

npx expo start
```

> **تێبینی:** وەشانەکانی ناو `package.json` بۆ **Expo SDK 53** ڕێکخراون. ئەگەر SDK ـیەکی نوێتر بەکاردەهێنیت، `npx expo install --fix` خۆی هەموویان ڕێک دەخات.

## دروستکردنی APK بە GitHub (بەبێ هەژمار)

ڕیپۆزیتۆرییەکە وۆرکفلۆی `.github/workflows/build-android-apk.yml` ـی هەیە. هەر کاتێک شتێک لە `business-card-maker/` بگۆڕێت، GitHub خۆی:

١. `npm install` دەکات
٢. `npx expo prebuild --platform android` (پرۆژەی ڕەسەنی ئەندرۆید دروست دەکات)
٣. `./gradlew assembleRelease` (APK دروست دەکات)
٤. APK لە بەشی **Actions → Artifacts** دادەنێت

بۆ دابەزاندن: بڕۆ بۆ تابی **Actions** ی ڕیپۆزیتۆرییەکە ← نوێترین ڕان ← لە خوارەوە لە **Artifacts** فایلی `business-card-maker-apk` دابگرە ← زیپەکە بکەرەوە ← APK بنێرە بۆ مۆبایل و دایبمەزرێنە (پێویستە «دامەزراندن لە سەرچاوەی نەناسراو» چالاک بکەیت).

> ئەم APK ـە بە کلیلی debug ی Expo ئیمزاکراوە — بۆ خۆت و تاقیکردنەوە تەواو باشە. بۆ Google Play کلیلی ئیمزای ڕەسەنی خۆت پێویستە (بڕوانە خوارەوە).

## دروستکردنی APK بە EAS (بۆ بڵاوکردنەوە)

```bash
npm install -g eas-cli
eas login
eas init            # projectId ی ڕاستەقینە لە app.json دادەنێت

# APK بۆ تاقیکردنەوە
eas build --platform android --profile preview

# APK ی نەشرکردن
eas build --platform android --profile production

# AAB بۆ Google Play
eas build --platform android --profile production-aab
```

پرۆفایلەکان لە `eas.json` دا دیاریکراون:

| پرۆفایل | ئەنجام |
|---|---|
| `development` | APK + development client |
| `preview` | APK ی ڕیلیس بۆ دابەزاندنی ڕاستەوخۆ |
| `production` | APK ی نەشرکردن (وەشان خۆکارانە زیاد دەبێت) |
| `production-aab` | App Bundle بۆ Google Play |

### پێش بنیاتنان
لە `app.json` ئەم دوو شتە بگۆڕە:
- `expo.android.package` — ناسنامەی پاکێجەکەت
- `expo.extra.eas.projectId` — بە `eas init` خۆی دادەنرێت

هەموو مۆدیوڵە ڕەسەنەکان (`expo-image-picker`، `expo-image-manipulator`، `expo-print`، `expo-sharing`، `expo-file-system`، `react-native-view-shot`، `react-native-svg`) لەگەڵ EAS Build گونجاون و پێویستیان بە کۆدی ڕەسەنی دەستی نییە.

## تێبینی تەکنیکی

- **فۆنتەکان**: هەموویان لە کاتی کردنەوەی ئەپەکەدا بار دەکرێن (`useAppFonts`). ئەگەر فایلێک بار نەبێت، ئەپەکە دەوەستێت — دەگەڕێتەوە بۆ فۆنتی سیستەم.
- **هەناردەکردن**: کارتەکە لە دەرەوەی شاشە بە ١٠٥٠ پیکسڵ ڕێندەر دەکرێت و `react-native-view-shot` وێنەی لێ دەگرێت — بۆیە کوالیتی چاپ پەیوەندی بە قەبارەی شاشەی ئامێرەکەوە نییە.
- **Expo SDK 54+**: ئەگەر بەرزی بکەیتەوە، `expo-file-system` و `expo-image-manipulator` API ـیەکی نوێیان هەیە؛ ئەو کاتە ئیمپۆرتەکان بگۆڕە بۆ `expo-file-system/legacy` و `expo-image-manipulator/legacy` یان بۆ API نوێیەکە.
