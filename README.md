# سیستەمی خشتەی هەفتانە — بەرنامەی ڕەسەنی ویندۆز

بەرنامەیەکی دێسکتۆپی ڕەسەن بۆ ڕێکخستنی خشتەی هەفتانەی مامۆستایان، بەبێ XAMPP و بەبێ ئینتەرنێت. داتاکە لەناو خودی کۆمپیوتەرەکەت هەڵدەگیرێت.

## تایبەتمەندییەکان
- تۆمارکردنی مامۆستایان، بابەتەکان، پۆلەکان (٧–١٢)
- میلاکی هەر مامۆستایەک + ئاگادارکردنەوە کاتێک پڕ دەبێت یان تێدەپەڕێت
- ڕۆژە بەتاڵەکانی مامۆستا (ڕۆژی تەواو یان بەشە وانەیەکی دیاریکراو)
- ڕێگری تەواو لە تێکهەڵچوون (مامۆستا لە دوو پۆل / پۆل بە دوو وانە)
- پێشنیاری ئۆتۆماتیکی مامۆستای بەردەست
- چاپکردنی خشتەکە (🖨)

## چۆنیەتی دامەزراندن (بۆ بەکارهێنەر)
١. فایلی `.exe` ی دامەزراندن دابگرە
٢. دووجار کرتەی لێ بکە — ویندۆز لەوانەیە ئاگاداری بدات (چونکە بەرنامەکە ئیمزای فەرمی نییە)، کرتە لە **More info → Run anyway** بکە
٣. شوێنی دامەزراندن هەڵبژێرە و **Install** بکە
٤. ئایکۆنی «خشتەی هەفتانە» لەسەر Desktop دروست دەبێت — وەک هەر بەرنامەیەکی ویندۆز

## چۆنیەتی دروستکردنی فایلی .exe (بۆ گەشەپێدەر)
لەبەر ئەوەی فایلی .exe تەنها لەسەر ویندۆز دروست دەبێت، GitHub خۆی دروستی دەکات:
١. ئەم پرۆژەیە باربکە بۆ ڕیپۆزیتۆرییەکی GitHub
٢. بڕۆ بۆ **Actions** — خۆی دەست پێ دەکات (لەسەر ویندۆز کۆمپایل دەکات)
٣. دوای تەواوبوون، لە **installer/** یان لە **Artifacts** فایلی `.exe` دابگرە

## هەڵگرتنی داتا
هەموو داتاکە لەم فایلەدا هەڵدەگیرێت:
```
C:\Users\<ناوەکەت>\AppData\Roaming\school-timetable\timetable-data.json
```
بۆ پاڵپشتی (backup)، ئەم فایلە کۆپی بکە.
